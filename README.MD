# Аутентификация и авторизация в современных веб-приложениях

🔗 **Работающий сайт:** https://silverom.github.io/web_sait/

## О проекте

Учебный сайт, посвящённый современным методам аутентификации и авторизации в веб-приложениях. Рассматриваются три основных подхода: классические сессии, JWT и OAuth 2.0.

## Структура проекта

web_sait/
── css/ # Стили сайта
│ ├── kube.min.css # Фреймворк Kube CSS
│ └── style.css # Кастомные стили
├── image/ # Изображения и диаграммы
│ ├── JWT_Tokken.png
│ └── Diagramm.png
├── js/ # Скрипты
│ └── main.js # Бургер-меню для мобильных
├── pages/ # Внутренние страницы сайта (9 файлов)
├── index.html # Главная страница
└── read.md # Информация о проекте (для ZIP)

## Используемые технологии

- **HTML5** — семантическая разметка
- **CSS3** — кастомные стили и адаптивная вёрстка
- **Kube CSS Framework** — сетка и компоненты
- **JavaScript** — мобильное меню

## Как запустить локально

Откройте index.html или любую другую страницу в папке page в браузере или через Live Server в VS Code.
